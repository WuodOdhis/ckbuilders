# Day 1: OffCKB & Cell Model

**Date:** April 23, 2026

## Environment Setup
Set up local devnet using OffCKB.
```bash
offckb init
offckb node
offckb accounts
```

## Cell Model vs. Account Model
- **State Storage:** Fragmented into cells rather than a global state tree.
- **Ownership:** Defined by lock scripts.
- **Parallelism:** UTXO-style architecture allows for parallel transaction processing.
