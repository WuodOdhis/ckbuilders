# Day 1: CellScript v0.16.1 Follow-Up

**Date:** June 20, 2026

## Objective

Pick up from the Week 7 blocker. ArthurZhang confirmed the `MintAuthority` bootstrap issue was real and fixed the example flow in CellScript `v0.16.1`. The goal today was to update the local CellScript checkout and understand the new path.

## What Changed

Updated the local CellScript repo to `v0.16.1` and reinstalled `cellc`.

```bash
cellc --version
# cellc 0.16.1
```

The important change is that token bootstrapping now lives in `launch.cell`.

There are two relevant actions:

- `bootstrap_token`: creates the first `MintAuthority` and token outputs
- `launch_token`: creates the first `MintAuthority`, initial token distribution, pool topology, LP receipt, and change token

That means the old circular problem is resolved. `token.cell` no longer has to explain where the first authority comes from by itself.

## CLI-First Builder Path

Arthur also clarified that the builder path should be CLI-first for now. I verified the core commands:

```bash
cellc abi examples/launch.cell --target-profile ckb --action launch_token
cellc entry-witness examples/amm_pool.cell --target-profile ckb --action swap_a_for_b --arg 2 --arg 0x1111111111111111111111111111111111111111111111111111111111111111 --json
cellc explain-assumptions examples/launch.cell --target-profile ckb --primitive-strict 0.16 --json
```

The practical lesson is simple: the builder should not hand-encode CellScript witness bytes. It should ask `cellc` for ABI and witness data, then build around those outputs.
